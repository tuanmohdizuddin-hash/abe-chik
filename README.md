# Belanja Adieb Hakiem

Aplikasi web untuk Adieb Hakiem (pelajar) menjejak perbelanjaan harian, mingguan dan bulanan. Tema silver-gold.

- Rekod perbelanjaan dengan **suara** (Bahasa Melayu, contoh: "makanan 7 ringgit 50 nasi ayam guna touch n go") atau **taip**
- Kategori untuk pelajar (Makanan, Minuman & Kopi, Pengangkutan, Yuran & Buku, Print & Alat Tulis, Data & Telefon, Sewa & Bilik, Dobi, Langganan, dll.) serta kategori sendiri
- Ikut cara bayar: Tunai, e-Wallet, Kad/Bank, DuitNow QR
- Dashboard: hari ini, minggu ini, bulan ini, baki bajet, carta harian, rumusan mingguan, carta kategori
- Eksport CSV; data disimpan dalam peranti (localStorage); boleh dipasang ke skrin utama (PWA)

Buka `index.html` atau hoskan dengan GitHub Pages (Settings → Pages → branch ini).
